# Screened Out! — Screen Addiction Awareness

An interactive web experience designed to raise awareness about unhealthy screen habits and encourage a healthier balance between online and offline life.

> **Don't just reduce, replace!**

## About the Project

**Screened Out!** is an interactive awareness website focused on helping users recognize unhealthy screen habits and make healthier choices in their daily lives.

Instead of simply encouraging users to spend less time on screens, the project focuses on replacing excessive screen use with meaningful offline activities and healthier habits.

The experience combines self-assessment, interactive challenges, educational content, and practical tips to make the topic more engaging and actionable.


## My Contribution

The project was originally developed as part of a team during the **DECI Level 2 Summer Camp**.

I was responsible for the website's **design and development**, including the implementation of its interactive features. I later revisited and further developed the project during **DECI Level 3**, improving the original experience and adding new interactive functionality.

Other team members contributed to the project's presentation and supporting materials.

## Features 

- Interactive screen-habit self-assessment
- Progress tracking during the assessment
- Personalized awareness feedback
- Offline challenge generator
- Practical tips for healthier screen habits
- Interactive educational content
- Quick knowledge quiz
- Responsive interface
- Dark mode
- Smooth scroll animations

## Development Journey

### Level 2 — Initial Version
The original version of **Screened Out!** was created during the DECI Level 2 Summer Camp as part of a digital awareness campaign.

The project started with a simple goal: make awareness about unhealthy screen habits more engaging than a traditional informational webpage.

### Level 3 — Further Development
During the DECI Level 3 Summer Camp, I returned to the project and continued developing it rather than starting from scratch.

I improved the existing experience and added more interactive functionality using JavaScript, including the assessment flow, dynamic results, challenges, habit interactions, theme preferences, and browser-based data persistence.

This gave me an opportunity to practice working with an existing codebase, understand how different parts of a web experience interact, and gradually improve a project over time.

## What I Learned

Through this project, I practiced:

- Building interactive web experiences with JavaScript
- Structuring and styling responsive web pages
- Designing user-focused interfaces
- Turning an awareness idea into an interactive experience
- Iterating on an existing project instead of starting from scratch
- Improving and maintaining an existing codebase over time
